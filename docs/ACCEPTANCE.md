## 使用边界

- 当前 schema 为 V1。未来版本升级应追加真实的跨版本迁移测试；当前已验证重复启动与拒绝未知版本不损坏数据。
- 上传文件追加保存，替换后旧媒体不自动回收；备份 ZIP 不自动清理。README 说明了维护与恢复方式。
- JSON 不含媒体文件，完整迁移应使用 ZIP 或停机复制数据目录。
- 自动化测试使用临时目录和专用端口，截图演示数据不会写入正式 `data/`。
- 本地验收阶段未对外发布服务；后续 GitHub 源码与安装包发布信息以仓库和 Release 记录为准。

```powershell
cd web

npm run build
npm run test:e2e
cd ..
node scripts/smoke.mjs release/navhub-windows-amd64.exe
```
